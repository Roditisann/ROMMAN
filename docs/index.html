ROMMAN

Merge multiple ROM hacks — with conflict detection and per-region control.
Download GitHub

ROMMAN loads multiple patches or full ROM dumps, analyzes which ROM addresses each hack modifies, detects overlaps, and merges them into a single output. When conflicts exist, you can resolve them by global priority or per-region Smart Merge.

Features

Formats
Input: IPS, BPS, XDelta, .bin/.nes/.md/.gen. Output: bin/nes/unh/ips/bps/xdelta.
Conflict control
Detects overlaps, clusters nearby regions, and supports Smart Merge per-region decisions.
Disassembly-aware
Profiles/rules, optional symbol map, build hook, and best-effort rebase for shifted disassembly rebuilds.
ROM fixups
Base CRC32/MD5 display, NES header handling, Genesis/GB/GBC/SNES checksum fixups.
Preview
Launch merged or individual hacks in a configured emulator (RetroArch/BlastEm/etc.).
CLI + GUI
Scriptable CLI and a simple black/white Tk GUI.

Quick Start

# Check conflicts
romman base.bin hack1.ips hack2.bps --check

# Merge with priority (first wins conflicts)
romman base.bin hack1.ips hack2.bps -o merged.bin --priority hack1.ips hack2.bps

# GUI
python -m romman.gui

Notes

  • Byte merge != semantic merge. A clean merge can still be logically incompatible.
  • Disassembly rebase is best-effort; ambiguous offsets are skipped to avoid corruption.
  • Always test merged ROMs in an emulator or appropriate hardware workflow.
